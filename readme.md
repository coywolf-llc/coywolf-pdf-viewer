# Coywolf PDF Viewer

> [!IMPORTANT]
> Coywolf PDF Viewer is no longer developed. Coywolf moved all of its sites from WordPress to [EmDash](https://emdashcms.com), and the plugin features it still uses are now in [Coywolf Pack for EmDash](https://github.com/coywolf-llc/coywolf-pack). This repository is archived and read-only.

## Use Coywolf Pack instead

Coywolf Pack doesn't have a PDF viewer. Its [File Downloads](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/files.md) module can offer PDFs, or any other file, as downloads with a download card. For the rest of what Coywolf built for WordPress, see [Coywolf Pack's modules](https://github.com/coywolf-llc/coywolf-pack#modules).

To add Coywolf Pack to an EmDash site, follow its [Getting started](https://github.com/coywolf-llc/coywolf-pack#getting-started) guide.

## What this plugin did

Embedded PDFs in posts and pages with a fast, self-hosted viewer, with a PDF library in the admin and a Coywolf PDF block.

## If you still use it

The last release, [v1.0.9](https://github.com/coywolf-llc/coywolf-pdf-viewer/releases/tag/v1.0.9), is still available, but it won't get updates, security fixes or support. The code stays here under the GPL-2.0-or-later license.
